# v0.8.0

This release moves the runtime to TextSlinger 0.5.0, which needs a newer Python and
numpy. The model and the runtime's layout and manifest format are unchanged, apart
from the Python folder name on macOS.

## Runtime

| Component | v0.7.0 | v0.8.0 |
|---|---|---|
| CPython (python-build-standalone) | 3.10.22 (20261009) | 3.13.18 (20261110) |
| textslinger | 0.4.0 | 0.5.0 |
| numpy | 1.26.4 | 2.5.5 |
| KenLM | 0.2.0 | 0.3.0, still built with `MAX_ORDER=12` |
| regex | 2026.9.29 | removed |

- On macOS the interpreter is now `bin/python3.13`. `manifest.json` gives the path, as before.
- textslinger 0.5.0 imports PyTorch and KenLM only when a model needs them, so the
  lazy-import patch for 0.4.0 is gone. The smoke test still checks that PyTorch is
  never imported.
- regex is needed only by TextSlinger's subword (LLM) models, not by the n-gram model.
- The stored CPython licence texts are from 3.13.18. OpenSSL 1.1 is gone; zlib-ng and
  zstd are added.

Each release carries `textslinger-runtime-<target>.zip` and a `.sha256` file for:

- `x86_64-pc-windows-msvc`, also used on Windows ARM64 under x64 emulation
- `aarch64-apple-darwin`
- `x86_64-apple-darwin`
