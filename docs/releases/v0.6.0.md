# v0.6.0

This release replaces Switchify's own prediction engine with a bundled runtime
for [TextSlinger](https://github.com/kdv123/textslinger), which Switchify PC is
moving its word suggestions to.

## TextSlinger runtime

Each release now carries `textslinger-runtime-<target>.zip` and a `.sha256` file for:

- `x86_64-pc-windows-msvc`, which Switchify PC also runs on Windows ARM64 under x64 emulation
- `aarch64-apple-darwin`
- `x86_64-apple-darwin`

Each archive is self-contained:
- standalone CPython 3.10.22
- numpy, regex and textslinger 0.4.0
- KenLM 0.2.0 built with `MAX_ORDER=12`
- the binary `lm_dec19_char_tiny_12gram.kenlm` model, redistributed with the TextSlinger authors' permission

`manifest.json` gives the interpreter and model paths and the model's alphabet. `notices/` holds the licences of every component and the KenLM source.

Every input is pinned by SHA-256. Each build must pass two checks before it is packaged:
- it loads the model and predicts without importing PyTorch;
- no native file depends on a library outside the runtime and the operating system.

textslinger 0.4.0 is patched so it imports PyTorch only for the models that need it ([kdv123/textslinger#2](https://github.com/kdv123/textslinger/pull/2)). textslinger requires Python 3.10, which reached end of life in October 2026; [kdv123/textslinger#3](https://github.com/kdv123/textslinger/issues/3) asks for newer versions.

See [the runtime documentation](../textslinger-runtime.md).

## Removed

The Rust n-gram library, the `switchify-prediction` CLI, the neural companion and
worker, the English models and the corpus and benchmark tooling are removed.
Releases up to v0.5.3 keep their assets, and the code remains in the repository's
history and tags.

Switchify PC integration is a separate application change.
