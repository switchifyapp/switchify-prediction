# v0.6.1

This release makes building the TextSlinger runtime independent of OSF.

## Model download

The model now comes from this repository's
[`textslinger-model-1`](https://github.com/switchifyapp/switchify-prediction/releases/tag/textslinger-model-1)
release first, and from OSF only if that fails. That release holds an unchanged
copy of the OSF file, redistributed with the TextSlinger authors' permission.
Whichever source is used must match the same pinned size and SHA-256.

Downloads now retry network errors, dropped connections and downloads that end
early. Bytes that don't match the pin are never retried or accepted.

## Runtime

The runtime archives contain the same components and versions as v0.6.0.
