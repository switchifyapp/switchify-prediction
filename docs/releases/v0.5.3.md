# v0.5.3

This release adds opt-in prediction from letters typed in order.

## Abbreviated words

`Predictor::predict_abbreviated` suggests a word when the typed text starts
with the word's first letter and contains some of its other letters in order.
For example, `abt` can suggest `about`, `ppl` `people` and `dont` `don't`.
Each result is an `AbbreviatedSuggestion` with `word`, `score`,
`language_score` and `abbreviated`. Exact prefix completions keep their
`predict` score and have `abbreviated: false`. Words that match only by
skipping letters are weighted by the fixed `ABBREVIATION_WEIGHT` of 0.5 and
flagged so callers can replace the typed text. The CLI enables it with
`predict --abbreviations`. See [abbreviated words](../abbreviations.md).

`predict` and its JSON are unchanged. The weight is a fixed starting value,
not a measured or calibrated probability that an abbreviation was meant.

## Compatibility and distribution

Root, neural companion and worker versions are synchronized at 0.5.3. Personal
database schema 1, the compact model format, the shipped `en-aac-oanc-v1`
model, the pinned neural model and worker protocol 3 are unchanged from
v0.5.2. CLI and worker bundles remain unsigned; applications sign their
embedded executables through their own release process.

Switchify PC integration is a separate application change.
