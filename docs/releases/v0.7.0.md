# v0.7.0

This release switches the runtime to TextSlinger's mixed-case model, so Switchify PC
can suggest words with their capitals, such as *I*, *London* and *Monday*.

## Model

`model/mix_case_c4_0.90_subtitle_0.75_12gram_4e-9.kenlm` replaces
`lm_dec19_char_tiny_12gram.kenlm`. It is TextSlinger's mixed-case 12-gram character
model from the same OSF project (ajm7t), redistributed with the TextSlinger authors'
permission. It comes from this repository's
[`textslinger-model-2`](https://github.com/switchifyapp/switchify-prediction/releases/tag/textslinger-model-2)
release first and from OSF (`jd8ku`) only if that fails, and must match the pinned
size and SHA-256 either way.

- Alphabet in `manifest.json`: `a`–`z`, `A`–`Z`, apostrophe and space. Unlike the
  previous model it has no full stop, comma, question mark or exclamation mark.
- Size: 33,508,755 bytes, up from 16,467,314.
- Ask for mixed-case words with `predict_lower=False` and spelling characters in both
  cases. With the defaults, predictions are lowercase as before.

The smoke test now also checks that a mixed-case prediction suggests *I*.

## Runtime

Python, TextSlinger, KenLM, numpy and regex are unchanged from v0.6.1.
