# v0.5.2

This release adds a neural companion bundle for Windows on ARM.

## Windows ARM64 worker

Releases now include
`switchify-prediction-neural-0.5.2-aarch64-pc-windows-msvc.zip`. It is built
natively on GitHub's `windows-11-arm` runner and has the same layout as the
other ARM64 bundles: one portable worker with no AVX2 variant, hashes and
dependency notices, and no model files. Like the x64 Windows worker, it links
the C runtime statically. The generation qualification now runs on Windows
ARM64 as well, and its reports name the runner architecture.

Debug and test builds now optimise the `gemm-common` and `gemm-f16`
dependencies. Their fp16 kernels assemble only once inlined, and unoptimised
builds failed on targets without fp16 in their baseline, such as
`aarch64-pc-windows-msvc`. Release builds are unchanged.

These are build and packaging measurements. They are not claims about
prediction quality or latency on any particular ARM device.

## Compatibility and distribution

Root, neural companion and worker versions are synchronized at 0.5.2. Library
behaviour, personal database schema 1, compact model format, the shipped
`en-aac-oanc-v1` model, the pinned neural model and worker protocol 3 are
unchanged from v0.5.1. The audit policy is unchanged. CLI and worker bundles
remain unsigned; applications sign their embedded executables through their
own release process.

Switchify PC integration is a separate application change.
