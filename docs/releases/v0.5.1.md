# v0.5.1

This release adds opt-in nearby-key prediction and reproducible dataset
benchmarks, and updates rustix to fix RUSTSEC-2026-0486.

## Nearby-key prediction

`KeyHitMap` and `Predictor::predict_with_hit_map` offer word suggestions after
one nearby-key substitution. A QWERTY preset is included; embedding applications
can supply their own key centers. Results include the language score, key
weight and explicit substitution metadata. The CLI enables this with
`--nearby-qwerty` for word suggestions.

The existing exact-prefix API and default CLI behavior are unchanged. Nearby
ranking can displace correct suggestions on clean input, so it remains opt-in.
It does not edit text automatically. Accepting a correction requires replacing
the application's owned unfinished prefix, rather than appending a suffix.
Search, Unicode boundary handling and exact-only requests are bounded and
covered by tests. See the [API documentation](https://github.com/switchifyapp/switchify-prediction/blob/v0.5.1/docs/key-hit-maps.md).

## Data and benchmark tooling

The repository now includes source-isolation and removal comparisons for the
current corpora, a broad word-frequency experiment, a pinned Google Books
sample experiment, and a reproducible nearby-key development benchmark. The
hit-map runner pins input hashes, uses Cargo's reported executable, and records
clean/noisy measurements and short-prefix diagnostics without publishing local
executable paths.

These are research and engineering measurements, not evidence of real AAC-user
benefit. No experimental corpus or blend is promoted. The shipped
`en-aac-oanc-v1` model, its vocabulary/counts and fingerprint remain unchanged.

## Compatibility and distribution

Root, neural companion and worker versions are synchronized at 0.5.1. Personal
database schema 1, compact model format, the pinned neural model and worker
protocol 3 are unchanged. Prior neural-generation qualification limits still
apply; this release does not change its production status.

Both lockfiles use rustix 1.1.6. Audit policy is unchanged, including the neural
companion's existing documented exceptions. CLI and worker bundles remain
unsigned; applications sign their embedded executables through their own
release process. Model weights are not redistributed in the neural bundles.

Switchify PC and Android integration are separate application changes.
